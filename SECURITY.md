# Security policy

This is a zero-backend **public, anonymous, read-only** demonstration. **Do not submit GitHub tokens, other credentials, private repository data or secrets** to this site.

For suspected vulnerabilities, prefer a [private GitHub security advisory](https://github.com/Codellei/cosw-demo/security/advisories/new) if enabled, or contact a repository maintainer privately. Do not open a public exploit report before disclosure coordination.

Supply-chain inputs are pinned. Eligible immutable release-lock updates may be promoted automatically **only after** a successful exact-head CI qualification and explicit administrator opt-in. Changes to the assembler, CSP, permissions, or Pages workflow still require human review. Failed automated updates never publish. Fork operators are responsible for protecting their default branch and configuring Pages and environment protections.
